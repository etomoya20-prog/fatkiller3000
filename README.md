# fatkiller3000

Телеграм-бот для группы худеющих: встречает новичков, считает индивидуальную норму
калорий, принимает ежедневные отчёты о еде в любом виде и раз в неделю публикует
в групповом чате сводку по всем участникам.

## Как это работает

**Новичок в группе.** Бот замечает вступление и пишет в чат приветствие с кнопкой,
ведущей в личку. Кнопка — диплинк, он же сообщает боту, из какой группы пришёл человек.

**Анкета в личке.** Шесть вопросов: пол, возраст, рост, текущий вес, целевой вес,
уровень активности. На выходе — дневная норма калорий и БЖУ.

Норма считается по формуле Миффлина-Сан Жеора: базовый обмен × коэффициент активности,
минус 20% на дефицит. Ниже базового обмена и ниже абсолютного минимума по полу
(1500 ккал мужчинам, 1200 женщинам) норма не опускается. Белок — 1.8 г на кг целевого
веса, жир — 0.9 г, углеводы — остаток.

**Ежедневный отчёт.** Пользователь присылает в личку что угодно:

- свободный текст — «завтрак овсянка 350, обед 600, ужин творог 250»;
- файл-выгрузку из приложения учёта калорий — CSV, XLSX, PDF, TXT;
- скриншот дневника питания.

Всё это разбирает OpenAI и возвращает калории с БЖУ. Если пользователь прислал итог
за весь день, запись вытесняет всё накопленное за эту дату; если отдельный приём пищи —
прибавляется к дневной сумме.

**Напоминание в 21:00 МСК.** Уходит тем, от кого за день не пришло ни одной записи.
Повторно за тот же день не приходит.

**Сводка по воскресеньям в 20:00 МСК.** В групповой чат уходит рейтинг участников:
сколько дней из семи человек уложился в норму, сколько дней вообще не отчитался,
средние калории за неделю. День засчитан, если калории попали в коридор ±10% от нормы.

## Команды

| Команда | Где | Что делает |
|---|---|---|
| `/start` | личка | Анкета, а если она заполнена — показ нормы |
| `/today` | личка | Итог за сегодня |
| `/profile` | личка | Норма калорий и БЖУ |
| `/again` | личка | Заполнить анкету заново |
| `/reset` | личка | Стереть записи за сегодня |
| `/help` | личка | Как пользоваться |
| `/join` | группа | Записаться в участники вручную |
| `/chatid` | любой | ID чата (только админам) |
| `/force_summary` | любой | Разослать сводку сейчас (только админам) |
| `/force_reminder` | любой | Разослать напоминания сейчас (только админам) |

## Устройство

| Файл | Отвечает за |
|---|---|
| `main.py` | Запуск: БД, бот, планировщик, админские команды |
| `config.py` | Переменные окружения, коэффициенты активности |
| `calories.py` | Формула Миффлина-Сан Жеора, расчёт БЖУ |
| `db.py` | Пул asyncpg и все запросы |
| `schema.sql` | Таблицы, накатывается при каждом старте |
| `llm.py` | Разбор отчётов через OpenAI |
| `scheduler.py` | Напоминания и недельная сводка |
| `handlers/group.py` | Приветствие новичков, отслеживание состава группы |
| `handlers/onboarding.py` | Анкета на конечном автомате |
| `handlers/intake.py` | Приём текста, файлов и картинок |

Данные лежат в PostgreSQL **на хосте**, не в контейнере — на сервере мало памяти.
Контейнер ходит в базу через `host.docker.internal`.

## Развёртывание

Сервер: `root@150.251.155.201`, каталог `/srv/fatkiller3000`.
База `fatkiller3000` и пользователь `fatkiller` уже созданы, пароль прописан
в `/srv/fatkiller3000/.env`.

Перед первым запуском заполните в `/srv/fatkiller3000/.env`:

```
BOT_TOKEN=          # от @BotFather
OPENAI_API_KEY=     # ключ OpenAI
ADMIN_IDS=          # ваш Telegram ID, через запятую если несколько
GROUP_CHAT_ID=      # можно оставить пустым
```

Дальше:

```bash
./deploy.sh
```

Скрипт коммитит изменения, пушит в GitHub, на сервере делает `git reset --hard`,
пересобирает образ и поднимает контейнер.

Полезное на сервере:

```bash
docker compose -f /srv/fatkiller3000/docker-compose.yml logs -f    # логи
docker compose -f /srv/fatkiller3000/docker-compose.yml restart    # перезапуск
```

## Настройка бота в Telegram

1. Создайте бота у @BotFather, токен — в `.env`.
2. Отключите Privacy Mode: `/setprivacy` → Disable. Иначе бот не увидит команды в группе.
3. Добавьте бота в группу и **сделайте администратором** — без этого Telegram не
   присылает события о новых участниках, и встречать новичков бот не сможет.
4. Проверьте: команда `/chatid` в группе, затем `/force_summary` в личке.

## Несколько групп

Бот рассчитан на работу сразу в нескольких группах — отдельный экземпляр под каждую
не нужен.

Профиль и дневник питания привязаны к человеку, а не к чату: у таблиц `users`
и `entries` нет `chat_id`. Человек, состоящий в двух группах, заполняет анкету один
раз, отчитывается один раз в день и получает одно напоминание — но попадает в сводки
обеих групп с одинаковыми цифрами.

К чату привязана только принадлежность: `group_members` — связка «многие ко многим»,
и сводка строится по составу конкретной группы. Участники группы A в сводке группы B
не появляются.

Что происходит на краях:

- **Вышел из одной группы из двух** — остаётся в сводке второй, напоминания приходят.
- **Вышел отовсюду** — напоминания прекращаются, данные сохраняются. Вернётся —
  анкету заполнять заново не придётся.
- **Бота выгнали из группы** — чат помечается неактивным, сводка туда не уходит,
  участники этой группы перестают получать напоминания, если других групп у них нет.

Оставьте `GROUP_CHAT_ID` пустым — тогда сводка автоматически уходит во все группы,
где состоит бот. Заполнять его нужно, только если сводку надо публиковать не везде;
несколько ID перечисляются через запятую.

Учтите: человек в двух группах показывает свои результаты обеим.

## Что стоит знать

Анкета живёт в памяти процесса. Если контейнер перезапустится, пока человек отвечает
на вопросы, ему придётся начать с `/start` — данные уже отвеченных вопросов не сохранятся.
Для шести коротких вопросов это приемлемо; если станет мешать, состояние переносится в БД.

Разбор отчётов стоит денег: каждое сообщение о еде — один запрос к OpenAI.
На `gpt-4o-mini` это копейки, но при росте группы имеет смысл посматривать на расход.

Участники группы видят в еженедельной сводке имена и результаты друг друга.
Это задумано, но людей стоит предупредить при входе в группу.
